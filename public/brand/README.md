# Swell Brand Kit

Generated by `node scripts/generate-brand-kit.js` — run again to regenerate all assets.

## Directory structure

```
public/brand/
├── tokens.css              ← All 6 brand token sets (uncomment one to activate)
├── README.md               ← This file
├── swell/                  ← Current brand (Swell actuel)
├── wavehold/
├── tidale/
├── surfpal/
├── localboard/
└── shackwave/

Each brand folder contains:
  logo-mark-light.svg         Mark on transparent bg (use on dark backgrounds)
  logo-mark-dark.svg          Mark on brand-bg rectangle
  logo-mark-mono-white.svg    White monochrome (print, dark overlays)
  logo-mark-mono-black.svg    Black monochrome (print, light backgrounds)
  wordmark-light.svg          Text-only wordmark, white
  wordmark-dark.svg           Text-only wordmark, black
  lockup-horizontal-light.svg Mark + wordmark, side by side (nav, header)
  lockup-horizontal-dark.svg  Mark + wordmark, side by side (light bg)
  lockup-vertical-light.svg   Mark + wordmark, stacked (splash, loading)
  lockup-vertical-dark.svg    Mark + wordmark, stacked (light bg)
  favicon.svg                 32×32 brand icon (browser tab)
  favicon-maskable.svg        512×512 maskable icon (Android PWA)
  og-image.svg                1200×630 default OG/Twitter card
  og-image-hossegor.svg       1200×630 OG for Hossegor pages
  og-image-graviere.svg       1200×630 OG for La Gravière pages
  manifest.json               PWA manifest with this brand's colors
  tokens.css                  CSS custom properties for this brand only
  email-header.html           Postmark email header template
```

## Where each asset is used

| Asset | Used in |
|-------|---------|
| `favicon.svg` | `<link rel="icon">` in all HTML pages |
| `favicon-maskable.svg` | `manifest.json` icons[] → purpose: maskable |
| `lockup-horizontal-light.svg` | nav `.preview-logo`, email header |
| `og-image.svg` | `<meta property="og:image">` on homepage/app.html |
| `og-image-hossegor.svg` | Spot landing page for Hossegor |
| `tokens.css` | Replace existing `:root` CSS vars in index.html, app.html, host.html |
| `manifest.json` | Replace `/public/manifest.json` |
| `email-header.html` | Postmark template — paste into each transactional template |

## Activating a brand (the fast path)

1. Pick a brand id (e.g. `wavehold`)
2. Copy `public/brand/wavehold/tokens.css` content into the `:root` block of your main CSS
3. Replace `public/manifest.json` with `public/brand/wavehold/manifest.json`
4. Replace `public/og-image.svg` with `public/brand/wavehold/og-image.svg`
5. Follow `MIGRATION.md` for domain, DNS, and full codebase rename

## Regenerating assets

```bash
node scripts/generate-brand-kit.js
```

The generator is fully deterministic — no network calls, no dependencies beyond Node stdlib.
Modify brand definitions in `BRANDS[]` at the top of the script, then re-run.

## OG image spot variants

`og-image.svg` is the homepage default (1200×630).
Each spot should have its own variant. To add more spot OG images, edit the generator:

```js
writeFile(path.join(dir, 'og-image-seignosse.svg'), ogImageSvg(b, 'Seignosse'));
```

Or use the template directly — it's a parametric SVG with the spot name as a string argument.
